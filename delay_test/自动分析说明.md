# 自动分析上升与下降延迟

本版新增 monitor_auto.py。main.c无需修改或重新烧录；IIR系数改变仍需保存生成配置、编译烧录。monitor_auto.py调用monitor.py的实时采集，因此两个Python文件要放在同一文件夹。

1. 关闭其他读取COM口的程序，解压本包，用其中的Python文件替换旧版本。
2. 安装依赖：python -m pip install -r requirements.txt
3. 实时采集并在关闭图窗后自动分析：
   python monitor_auto.py --port COM5 --out delay_iir64.csv --count 10
   替换COM编号。先静置2秒，每次快按、保持0.5秒、快松，间隔2～3秒。建议记录12～15次以备剔除异常。关闭图窗结束，随后自动生成结果。不会自动在第10次关闭图窗。
4. 已有CSV无需重新采集：
   python monitor_auto.py --csv delay_iir64.csv --count 10
   接受原main.c输出的11列CSV。不需要连接开发板，不需要鼠标拖选。
5. 输出文件夹名称为 CSV名_analysis_时间戳，位于CSV所在目录。events.csv记录全部Status事件；valid是算法有效性、used是是否纳入前10次汇总、reason是原因。summary.csv汇总6项延迟的样本数、中位数、均值、样本标准差和范围。event_XX.png自动保存每个完整事件的标注波形，summary.png显示各次延迟，results.json保留详细交叉时间。

6项延迟（全部单位ms）：
- rise_filter_half_delay_ms：最终波形向上越自身50%幅度的时间，减滤波前波形向上越自身50%的时间。
- fall_filter_half_delay_ms：最终波形向下越自身50%的时间，减滤波前波形向下越自身50%的时间。
- rise_status_minus_pre_ms：Status 0→1时间，减滤波前信号越ON门限时间。
- rise_status_minus_post_ms：Status 0→1时间，减最终差值信号越ON门限时间。
- fall_status_minus_pre_ms：Status 1→0时间，减滤波前信号越OFF门限时间。
- fall_status_minus_post_ms：Status 1→0时间，减最终差值信号越OFF门限时间。

ON=Finger threshold+Hysteresis；OFF=Finger threshold-Hysteresis，使用CSV每帧实际值。滤波前差值=raw_pre-baseline；最终判定差值采用固件输出diff。半高分析使用各自Rawcount静置水平和事件峰值。各个波形半高和Status门限参考不同，不要将6项中的半高延迟当作两个Status延迟之差。图上的竖线为门限交叉及Status边沿，半高交叉的时间也保存在events.csv/results.json中。

自动事件分组以Status完整0→1→0为依据，250ms以内反复跳变归到同一组并拒绝作为干净事件；不能把没有触发Status的按压自动算作有效事件。Status连续为1但中间有多次物理按压时，可能被多峰检测拒绝，也可能不能完全区分；需检查自动事件图。软件不会替你认定全部物理按压是否被检测到。

上升/下降门限取相应Status边沿之前最近一次交叉，避免把更早的孤立噪声交叉计入。多次门限交叉会在reason中标记，仍应目视核对图形。缺帧、复位/时间倒退、事件不完整、静置不足、半高多次交叉、信号弱或未恢复会拒绝或报错。程序不会为被拒绝事件编造延迟。

默认每侧最多保留800ms静置余量。IIR16释放很慢或长按后信号未恢复，增加测试间隔；必要时：
   python monitor_auto.py --csv delay_iir16.csv --count 10 --margin-ms 1500
相邻事件边界会在两次事件之间限制，不会把无限长时间混入一个事件。

计数是前10次有效事件，而不是保证物理前10次。若有效事件不足10次，结果会显示实际数量并警告；补采并分析新文件，不要忽略警告。自动分析没有外部接触时间参考，不代表从真实接触到Status的绝对延迟；CIC2仍在两条信号中，不测CIC2延迟。

采样约10ms，时间戳1ms；交叉插值小数不是精度。平台饱和不能单凭这些CSV完全自动排除，仍须检查波形。

IIR定义更正：软件IIR y=(N/256)x+(1-N/256)y_previous。128仍有滤波，当前值权重50%；64为25%、32为12.5%、16为6.25%。真正无软件IIR须取消该滤波勾选。

验证：Python语法、10个已知上升/下降延迟的合成事件、缺帧拒绝与Status抖动分组已验证。本次没有用户实际CSV，真实事件识别仍需用数据核对。
